> Bố cục trực quan, lọc tức thì theo nhóm danh mục, đánh dấu yêu thích ⭐, chọn hàng loạt xử lý nhanh và kéo thả sắp xếp thứ tự linh hoạt.

  <img src="docs/screenshots/01_workspace_table_view.jpg" alt="Bàn làm việc thống nhất" width="92%" style="border-radius: 18px; box-shadow: 0 16px 40px rgba(0,0,0,0.12);" />
  <p><i>Giao diện quản lý Danh mục liên kết hệ thống, Form sản phẩm Tết và Báo date vận hành hàng ngày</i></p>

### 2. Tìm Kiếm Toàn Năng FM Spotlight (`Ctrl + K`)
> Tra cứu tức thời mọi dữ liệu từ tài khoản, liên kết, danh bạ cửa hàng cho đến các trang hệ thống chỉ trong một phím bấm.

<div align="center">
  <img src="docs/screenshots/02_spotlight_search.jpg" alt="Tìm kiếm nhanh Spotlight" width="76%" style="border-radius: 20px; box-shadow: 0 20px 50px rgba(0,0,0,0.16);" />
  <p><i>FM Spotlight gợi ý thông minh, tra cứu mã cửa hàng FM09, POS, Bravo, Google Drive trong &lt; 10ms</i></p>
</div>

* 🔎 **Tìm kiếm đa tầng**: Hỗ trợ lọc theo danh mục (`Tab`), gợi ý từ khóa phổ biến và lưu lịch sử tra cứu gần nhất.
* ⌨️ **Điều hướng bàn phím hoàn chỉnh**: Di chuyển `↑` `↓`, chọn `Enter`, chuyển tab bộ lọc `Tab`, đóng nhanh `Esc`.
* 🛡️ **Giao diện kính mờ Liquid Glass**: Khử hoàn toàn hiện tượng lọt sáng và chồng chữ, hiển thị sắc nét ở cả chế độ Sáng (Light) và Tối (Dark).

  <img src="docs/screenshots/03_quick_notes_ai_scanning.jpg" alt="Ghi chú nhanh và quét văn bản AI" width="86%" style="border-radius: 18px; box-shadow: 0 16px 40px rgba(0,0,0,0.14);" />

### 🔒 Tiêu Chuẩn Bảo Mật Cấp Doanh Nghiệp
- **Két mã hóa Vault**: Tự động dọn dẹp bộ nhớ tạm (Clipboard) sau **45 giây** kể từ khi sao chép mật khẩu.
- **Mã hóa file sao lưu (.fmbackup)**: Dữ liệu được bảo vệ bằng thuật toán mã hóa đối xứng **AES-GCM-256** kết hợp mã băm kiểm tra tính toàn vẹn **SHA-256**.
- **Khóa bảo vệ không gian làm việc (Privacy Shield)**: Tính năng mã PIN 6 số với cơ chế tự khóa sau thời gian không hoạt động (15/30 phút).

## ⌨️ Bảng Phím Tắt Tiện Dụng

| Phím tắt | Tác vụ thực hiện | Vị trí áp dụng |
|---|---|---|
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | Bật thanh tìm kiếm toàn năng FM Spotlight | Bất kỳ đâu trên ứng dụng |
| <kbd>Alt</kbd> + <kbd>N</kbd> / <kbd>Ctrl</kbd> + <kbd>J</kbd> | Mở hoặc thu nhỏ cửa sổ Ghi chú nhanh (Quick Note) | Bất kỳ đâu trên ứng dụng |
| <kbd>Ctrl</kbd> + <kbd>\</kbd> | Thu gọn hoặc mở rộng thanh điều hướng Sidebar | Toàn hệ thống |
| <kbd>Phép tính</kbd> + <kbd>=</kbd> | Tính toán tự động và in kết quả tức thì | Bên trong nội dung ghi chú |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Chuyển đổi nhanh qua lại giữa các bộ lọc tìm kiếm | Hộp thoại Spotlight |
| <kbd>Esc</kbd> | Đóng nhanh cửa sổ nổi, modal hoặc popover đang hiển thị | Toàn hệ thống |

## 🚀 Hướng Dẫn Cài Đặt Dành Cho Lập Trình Viên

### 1. Yêu cầu tiên quyết
- **Node.js**: Phiên bản 18.x trở lên.
- **npm**: Phiên bản 9.x trở lên.

### 2. Thiết lập dự án cục bộ
```bash
# Clone kho lưu trữ
git clone https://github.com/gochee-nhdk/fm-workspace.git
cd fm-workspace

# Cài đặt toàn bộ dependencies cho Client & Server
npm run setup

# Khởi chạy đồng thời Frontend và Backend trong môi trường dev
npm run dev
```

### 3. Kiểm thử & Đóng gói sản phẩm
```bash
# Chạy toàn bộ bộ kiểm thử tự động (Unit, Security, Business Logic)
npm test

# Kiểm thử riêng biệt cho phía giao diện Client
npm --prefix client test -- --run

# Biên dịch gói sản xuất tối ưu (Vite Production Build)
npm --prefix client run build
```
